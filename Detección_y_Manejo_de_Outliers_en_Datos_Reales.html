Detección de outliers 🚨¶

Dentro de nuestra base de datos es posible que existan datos atípicos que perjudiquen el correcto analisis para las diversas variables. Por ello, es importante detectar sí existen datos atípicos y dado el caso identificar de cuales datos se tratan para tomar decisiones de sobre que hacer con ellos.

Método de los rangos intercuartílicos (IQR)

for i in data.columns: #Cálculo de cuatiles y de IQR
    Q1 = data[i].quantile(0.25)
    Q3 = data[i].quantile(0.75)
    IQR = Q3 - Q1
    lower_bound = Q1 - 1.5 * IQR
    upper_bound = Q3 + 1.5 * IQR
    outliers_iqr = data[(data[i] < lower_bound) | (data[i] > upper_bound)]
    print(f"\n - Variable: {i}")
    print(f" - Q1: {Q1:.2f}")
    print(f" - Q3: {Q3:.2f}")
    print(f" - IQR: {IQR:.2f}")
    print(f" - Límite inferior: {lower_bound:.2f}")
    print(f" - Límite superior: {upper_bound:.2f}")
    print(f" - Cantidad de outliers: {len(outliers_iqr)}")
    print(f"\nOutliers por IQR en la variable '{i}':")
    if not outliers_iqr.empty:
        print(outliers_iqr[i])
    else:
        print(" - No se encontraron outliers.")

Manejo de outliers 🧹¶

Como nuestros métodos de detección de outliers confirmaron, hay variables que contienen outliers y afectarían el correcto analisis de las mismas. Para ello, optaremos por convertilos en valores faltantes para su posterior imputación. Esto lo haremos debido a que hay una variable con un gran número de outliers por lo que eliminarlos afectaría considerablemente el estudio.

def replace_outliers_with_nan(df):
    data_out = data.copy()

    for col in data_out.columns:
        if pd.api.types.is_numeric_dtype(data_out[col]):
            Q1 = data_out[col].quantile(0.25)
            Q3 = data_out[col].quantile(0.75)
            IQR = Q3 - Q1
            lower_bound = Q1 - 1.5 * IQR
            upper_bound = Q3 + 1.5 * IQR

            outlier_mask = (data_out[col] < lower_bound) | (data_out[col] > upper_bound)
            data_out.loc[outlier_mask, col] = np.nan

            print(f"🧹 Reemplazados {outlier_mask.sum()} outliers con NaN en '{col}'")

    return data_out

from sklearn.metrics import mean_squared_error, mean_absolute_error

def evaluate_imputation(original_df, imputed_df, df_with_nans):

    results = {'Feature': [], 'MSE': [], 'MAE': []}

    for column in original_df.columns:
        # Only evaluate where data was originally missing
        missing_mask = df_Nan[column].isna()

        if missing_mask.sum() > 0:
            original_values = original_df.loc[missing_mask, column]
            imputed_values = imputed_df.loc[missing_mask, column]

            mse = mean_squared_error(original_values, imputed_values)
            mae = mean_absolute_error(original_values, imputed_values)

            results['Feature'].append(column)
            results['MSE'].append(mse)
            results['MAE'].append(mae)

    return pd.DataFrame(results)

def evaluar_errores(df_original, df_imputed):
    resultados = []

    for col in df_original.columns:
        mae = mean_absolute_error(df_original[col], df_imputed[col])
        media_real = df_original[col].mean()
        error_relativo = mae / media_real
        if error_relativo > 0.2:
            significativo = 'Sí'
        else:
            significativo = 'No'

        resultados.append({
            'Variable': col,

Resumen de lo realizado:¶

Para la detección de outliers, se aplicó el método basado en el Rango Intercuartílico. Esta metodo consiste en calcular el primer cuartil y el tercer cuartil de cada variable numérica,teniendo como resultado el rango intercuartílico . Los valores que se encuentran por debajo de Q1 - 1.5IQR o por encima de Q3 + 1.5IQR se consideran outliers. Esta metodologia es bastante efectiva para identificar valores extremos sin depender de supuestos de normalidad en la distribución de los datos. Luego de detectarlos, estos valores fueron reemplazados por NaN para imputarlos mediante un modelo de machine learning.

Conclusiones:¶

Impacto de los Outliers:

Los outliers son valores extremos que pueden alterar significativamente los resultados de un análisis. En particular, su presencia tiende a distorsionar medidas fundamentales como la media, la desviación estándar y puede incluso afectar la calidad de los modelos predictivos al provocar sesgos. Durante este trabajo, se observó que los outliers modificaban la distribución natural de los datos, Razon por la cual se realizo todo el manejo para garantizar un análisis más confiable.

Utilidad de Eliminarlos o Imputarlos:

El manejo de outliers puede realizarse de dos maneras principales: eliminándolos o imputándolos. Eliminarlos resulta útil cuando estos valores provienen de errores de medición, registros incorrectos o situaciones que no son represntativas por lo que es probable que no se vea afectada la situación que se esta estudiando. Sin embargo, la imputación representa una estrategia más efectiva ya que permite preservar la cantidad presente en la información original, por lo que cuando imputamos despues de eliminar los outliers se logra preservar la estructura estadisticas de los datos, respetando la forma de sus distribuciones sin introducir sesgos importantes.

Recomendaciones sobre el Manejo de Valores Extremos en Contextos Reales:

En contextos reales, lo ideal seria que primero se analice mas o profundo la data y el contexto de los outliers para saber si estos son: errores, situaciónes que representen una excepción o que exista una variabilidad como tal en esos datos.No es recomendable eliminar los valores extremos sin antes tener en cuenta esos aspectos.Cuando finalmente se decide tratar estos datos se recomendaria usar metodos mas complejos de imputación (como: Random Forest, Gradient Boosting) o técnicas iterativas que respeten las relaciones entre variables. Finalmente, es esencial documentar el proceso de tratamiento de outliers para asegurar una transparencia en todo el proceso.
